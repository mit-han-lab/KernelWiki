## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->

This is the sgl-kernel part of https://github.com/sgl-project/sglang/pull/7762. A series of PRs will enable running [DeepSeek-R1-W4AFP8](https://huggingface.co/Barrrrry/DeepSeek-R1-W4AFP8) using sglang.

Additionally, this kernel supports other MoE models with INT4 MoE weight and FP8 activation quantization.

Co-author: yicwang <yichen.wang@bytedance.com>
