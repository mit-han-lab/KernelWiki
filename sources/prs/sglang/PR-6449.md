## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->
When benchmarking DeepSeek-V3‘s prefilling stage with DP + EP under large batchsize and seqlen, the tensor size will exceed the range of int32_t, then illegal memory access occurs on fp8_quant cuda kernel and triton kernel.

Error reproduction:
   Running Deepseek-v3 with DP32+EP32(4 H20x8 nodes), batch=128(batch=4 on each dp rank), seqlen=8192.
```bash
# launch server
export NCCL_IB_GID_INDEX=3
this_rank=1
init_addr=172.0.0.1:20000
python3 -m sglang.launch_server --model-path /mnt1/DeepSeek-V3 \
        --trust-remote-code  --tensor-parallel-size 32  --dp-size 32 \
        --enable-dp-attention \
        --enable-ep-moe  --enable-deepep-moe --deepep-mode normal --disable-cuda-graph \
        --dist-init-addr ${init_addr} --nnodes 4 --node-rank ${rank}  \
        --host 0.0.0.0 --port 30000 --mem-fraction-static 0.4 \
        --chunked-prefill-s
