## Motivation

<!-- Describe the purpose and goals of this pull request. -->

The current dsv32 attention implementation uses a single TileLang kernel for both prefill and decode.
This kernel is optimized for prefill, but during decode it launches very few thread blocks, resulting in poor CU utilization and degraded performance.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Added a dedicated kernel for sparse decode forward. The new kernel splits work along the top-k dimension to increase parallelism and improve CU utilization.
- Add a separate merge kernel to combine partial results.
