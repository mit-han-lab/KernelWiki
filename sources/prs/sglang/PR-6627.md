## Motivation

In ep_moe kernel _pre_reorder_triton_kernel_ and _post_reorder_triton_kernel_, every inner loop recomputes
offset = start_offset + tl.arange(...)

The optimization is to create a constant once:
vec = tl.arange(0, BLOCK_SIZE)
and inside the loop use idx = start_offset + vec

The benefit is one less instruction each iteration. The warp scheduler can vectorize the access pattern.
Per benchmark result the kernel gains 10-15% performance.
