## Motivation

The current implementation of MLA is slow when when handling long prefix lengths, such as sequences with 32k input length, as highlighted in issues like #5031.

Profiling revealed that the attention kernel's slow runtime is the primary bottleneck.  Currently, we perform absorption during chunked prefilling, but this approach is inefficient for long prefix lengths, as MLA with absorption has overly large computational intensity when `q` contains many tokens. Conversely, while multi-head attention (MHA) is computationally efficient, materializing key-value (KV) heads often leads to out-of-memory (OOM) errors.

we propose dividing long prefix KV caches into multiple chunks. The output tensors and log-sum-exp (LSE) states for each chunk can be merged into a single accumulated output and LSE state. This approach enables MHA during chunked prefilling while avoiding OOM issues.
