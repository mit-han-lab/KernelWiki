- Improve longer-context kernel performance on MI355.

## Modifications

<!-- Detail the changes made in this pull request. -->

- Enable the new tilelang partial+combine path with MI300 config: block_I=32, threads=128, block_per_cu=1. Drop the v1 kernel on MI300.
- Add inner_iter / n_groups for longer context so grid/CU ≥ block_per_cu and performance scales better.
- In partial kernel, put Q in shared when inner_iter == 1, and in fragment when inner_iter > 1 (reuse Q across KV groups / better occupancy).
