## Motivation

The original moeTopK kernel reads data from global memory topk times, resulting in significant performance overhead. By finding the top-2 elements in each iteration, we can reduce global memory accesses to topk/2 times, substantially improving kernel efficiency.

## Modifications

<!-- Detail the changes made in this pull request. -->
To minimize global memory access, we modified each thread to maintain its local top-2 elements. These partial results are then reduced in shared memory to compute the global top-2 values. This optimization significantly reduces the visits of global memory when topk is big.

Additionally, we observed that the original moeTopK kernel exhibits O(topk × (N/TPB) × topk) complexity. We can eliminate the innermost topk factor by modifying input values in-place, which is safe since these inputs are not used after kernel execution.
