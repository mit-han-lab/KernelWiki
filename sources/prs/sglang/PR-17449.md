## Motivation
@humansand

https://github.com/sgl-project/sglang/issues/17093
This PR adds mxfp8 quantization support to SGLang, using Triton for dense linear layer, and existing mxfp8 CUTLASS groped GEMM kernel in sgl-kernel from https://github.com/sgl-project/sglang/pull/13731 for MoE.

Online mxfp8 quantization from bf16 checkpoints and serving mxfp8 checkpoints directly are both supported.
