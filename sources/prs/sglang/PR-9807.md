## Motivation

The fp4_quantize kernels use `cvt with .e2m1x2` instructions with guards that are sm100a exclusive, which make them fail on sm103a.

## Modifications

- Replace the macros that guard `cvt with .e2m1x2` with more simpler cutlass macros for both sm_100a and sm_103a.
- Move the common functions to header file `nvfp4_quant.cuh`
- Add sm_version check to the fp4 pytorch ops for sm_100 and sm_103, so the error messages are better. Otherwise, the ops would fail with accuracy error instead of throwing exceptions.
