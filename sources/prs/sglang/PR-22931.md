## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Commit `34ddf135fd` introduced `recursive_replace()` in `TransformersBase`, which replaced every HF `*RMSNorm` module with SGLang's `sgl_kernel.rmsnorm`. The two kernels differ in rounding order: `sgl_kernel.rmsnorm` multiplies the weight in fp32 then casts, while HF's `LlamaRMSNorm` casts the normalized output to the activation dtype first, then multiplies. Under int4wo-128 quantization this ~1-ULP difference compounds across 32 transformer layers and flips 3 borderline MMLU questions (0.703 → 0.656).

#22435 introduced a naive fix which was reverting the change, but that led to a significant perf regression.

This PR adds a JIT kernel (`rmsnorm_hf`) that replicates HF's cast-before-weight-multiply order exactly, recovering accuracy with less throughput regression.
