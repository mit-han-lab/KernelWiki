## Summary

Optimize the large-shape `triton_group_norm_silu` chunked apply stage used by HunyuanVideo VAE decode.

- Add a scalar-affine apply kernel for aligned chunked rows where each program covers a single channel, avoiding per-element `idx // spatial_size` and vector affine loads.
- Keep the existing generic apply kernel as fallback for smaller or unaligned chunked cases.
- Add a standalone benchmark/profiling helper for this kernel.

Base/evidence commits: `origin/main` at `144038fba`, PR at `e844f696d`.

## H200 Benchmark

GPU: H200 on `radixark03`, BF16, `CUDA_VISIBLE_DEVICES=1`, `rounds=2`, `warmup=25`, `rep=100`.

| Case | Shape | Branch | Native us | Fused us | Speedup |
|---|---:|---|---:|---:|---:|
| HunyuanVideo VAE large | `1x128x20x256x256` | `main` | 4716.98 | 295.01 | 15.989x |
| HunyuanVideo VAE large | `1x128x20x256x256` | `PR` | 4714.42 | 259.66 | 18.156x |

NCU for the apply stage showed the optimized kernel reducing apply-stage time from 255.17 us to 178.08 us, with registers dropping from 48 to 43 and DRAM throughput rising from 51.86% to 74.13%.
