## Motivation

- [x] The original cuda kernel implementation only supported float32, while inference inputs typically use bfloat16 or float16 dtypes, so I fixed it.
- [x] The CUDA kernel currently lacks type-specific vectorization length handling and doesn't account for non-divisible cases.
- [x] The scale computation could be moved outside topk when `a1_scales_ptr != nullptr` and `use_per_token_if_dynamic` is true, reducing redundant global memory reads during topk iterations
- [x] In benchmark script, the input tensor allocation was mistakenly included in the timing function.
- [x] Unit tests were not added.
