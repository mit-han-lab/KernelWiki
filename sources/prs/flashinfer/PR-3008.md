## 📌 Description

<!-- What does this PR do? Briefly describe the changes and why they’re needed. -->

- Add programmatic dependent launch (PDL) support to `rmsnorm_fp4quant` and `add_rmsnorm_fp4quant` CuTe DSL kernels
- Wire `--enable_pdl` through to the FP4 quant benchmarks in `flashinfer_benchmark.py`

The regular rmsnorm variants (rmsnorm, fused_add_rmsnorm, rmsnorm_quant, fused_add_rmsnorm_quant) all support PDL for kernel overlap on SM90+. The FP4 quantization fusion variants were missing this support.
