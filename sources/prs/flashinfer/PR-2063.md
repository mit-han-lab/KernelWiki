## 📌 Description

- Small optimization to the activation kernel for block-FP8 MoE for large batch size.

| BS | Baseline, us | Optimized, us |
| ------------- | ------------- | ------------- |
| 1 | 2.4  | 2.1  |
| 32  | 3.5  | 2.6 |
| 256  | 21.7  | 8.7  |
| 1024 | 84.4  | 23.8  |
| 4096  | 333 | 87.0  |
| 16384  | 1330  | 365  |

- Adding micro-benchmark for DS FP8 implemented by @IwakuraRein.
