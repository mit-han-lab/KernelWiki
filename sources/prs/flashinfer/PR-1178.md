## 📌 Description

<!-- What does this PR do? Briefly describe the changes and why they’re needed. -->
For inputs with many `-inf` masks (e.g. topk masked logits), our current softmax kernel produces all `NaN` results when a thread  sees a slice of input made up entirely of `-inf`s. This pr adds checks to fix it.
