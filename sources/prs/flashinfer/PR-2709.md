## 📌 Description

This PR adds a high-performance **Mamba2 Structured State-Space Duality (SSD) combined forward kernel** targeting Blackwell (SM100+) GPUs, implemented using NVIDIA's CuTe DSL. The kernel fuses the entire SSD chunk-scan forward pass — including cumulative sum preprocessing, chunk state computation, inter-chunk state passing, and output projection — into a single persistent kernel launch.

### Features

- **Datatypes**: bf16 I/O, bf16/fp16 state cache (fp32 state not yet supported)
- **D tensor fusion**: optional additive bias with per-head (`d_has_hdim=True`) or broadcast (`d_has_hdim=False`) modes
- **Z gating**: optional sigmoid gating on the output
- **Initial states**: optional user-provided initial hidden states
- **Variable-length sequences**: packed varlen via `seq_idx` + precomputed chunk metadata
- **Batched mode**: uniform-length sequences without varlen overhead
- **CUDA graph compatible**: all allocations cached, no host-device sync in the hot path
