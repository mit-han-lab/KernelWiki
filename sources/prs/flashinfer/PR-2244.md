## 📌 Description

`cudaStreamSynchronize` in `CutlassGroupwiseScaledGEMMSM120` breaks CUDA graph capture and will fail explicitly starting CUDA 13.0.

**Changes:**
- Removed `cudaStreamSynchronize(stream)` and associated error handling from `gemm_groupwise_sm120.cuh` (lines 174-178)
- Added `torch.cuda.synchronize()` calls in `tests/gemm/test_groupwise_scaled_gemm_fp8.py` after GEMM operations to ensure results are ready before assertions
- Aligns SM120 implementation with SM100 patterns which don't synchronize after `gemm.run(stream)`

This approach follows separation of concerns: the kernel implementation remains asynchronous and CUDA graph compatible, while tests explicitly synchronize when needed to verify results.
