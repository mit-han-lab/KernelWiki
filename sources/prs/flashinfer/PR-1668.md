## 📌 Description

We are adding a new BF16 GEMM backend named TGV as a more performant alternative to cuBLAS on small problem sizes. TGV GEMMs are optimized for minimum latency use cases and shown to achieve up to 60% speedup on B200 (gpcclk=1800MHz) compared to cuBLAS in our unit tests (see attached table).
