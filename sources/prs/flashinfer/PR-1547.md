## 📌 Description

This change replaces the use of cudaGetDeviceProperties with cudaDeviceGetAttribute when querying the number of GPU Streaming Multiprocessors. Rather than retrieving the entire device properties, the updated approach directly fetches only the needed attribute (cudaDevAttrMultiProcessorCount), reducing unnecessary overhead.
