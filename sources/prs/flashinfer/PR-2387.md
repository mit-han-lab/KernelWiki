## Algorithm
The algorithmic differences between the new `selective_state_update_kernel_producer_consumer_horizontal` and the older Hopper-specific `selective_state_update_kernel_producer_consumer_vertical` are summarized below. Each CTA processes a single head. In the `vertical` case, each warp processes a row, and then performs a reduction using `shfl_sync` intrinsics.
