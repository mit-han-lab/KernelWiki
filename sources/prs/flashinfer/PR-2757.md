## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add GPU-accelerated NVFP4 quantization and dequantization kernels for KV cache
  with linear (non-swizzled) block scale layout.

  - **Dequantization** (`nvfp4_kv_dequantize`): SM80+, E2M1 LUT + vectorized memory
  access,
    dynamic shared memory to support arbitrary K dimensions
  - **Quantization** (`nvfp4_kv_quantize`): SM100+, uses PTX
  `cvt.rn.satfinite.e2m1x2.f32`
  - Two-level scaling: per-tensor FP32 `global_scale` + per-block FP8 E4M3
  `block_scales`
  - `@backend_requirement` guards for SM version validation at API level
  - Cross-device consistency checks for all tensor arguments
  - CUDA graph compatible (no implicit host-device transfers)
