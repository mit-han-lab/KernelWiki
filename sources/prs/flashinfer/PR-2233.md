## 📌 Description

## Fused RMSNorm + FP4 Quantization Kernels (CuTe-DSL)

This PR adds two high-performance fused kernels implemented in CuTe-DSL for Blackwell (SM100+) GPUs:

- **`rmsnorm_fp4quant`**: Fuses RMSNorm and FP4 quantization into a single kernel
- **`add_rmsnorm_fp4quant`**: Fuses residual add, RMSNorm, and FP4 quantization into a single kernel

### Features
- Supports both **NVFP4** (block_size=16, E4M3 scales) and **MXFP4** (block_size=32, UE8M0 scales) formats
- FP16 and BF16 input support
- Hidden sizes from 64 to 32K+

### Files Added
- `flashinfer/cute_dsl/rmsnorm_fp4quant.py` - RMSNorm + FP4 quant kernel
- `flashinfer/cute_dsl/add_rmsnorm_fp4quant.py` - Add + RMSNorm + FP4 quant kernel
