## 📌 Description

In GDN prefill kernel, this line of code will cause redundant cudaMalloc/cudaFree in kernel execution, which harms runtime performance. This workspace buffer is used for TMA store output.
https://github.com/flashinfer-ai/flashinfer/blob/a49b45336e56e4615eae102cf29d5110293d9130/csrc/flat/prefill/prefill_kernel_delta_rule_sm90.cuh#L132

This PR replaces this with a workspace buffer created by torch with the same size (# of SMs * 128B), removing redundant cudaMalloc/Free function call.
