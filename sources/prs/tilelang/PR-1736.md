## Summary

- Add `SwizzleMode` enum to detect swizzle layout types (Quarter/32B, Half/64B, Full/128B)
- Implement `DetectSwizzleMode` and `MergeSwizzleLayouts` functions in `gemm_layouts.cc`
- When layout inference encounters conflicting swizzle layouts for the same buffer, automatically merge to the smaller granularity instead of raising an error
- Refactor `GemmWGMMA.infer_shared_layout` to select swizzle layout based on continuity

## Motivation

When multiple operations (e.g., GEMM + Copy) require different swizzle layouts for the same shared memory buffer, the layout inference would fail with a conflict error. Since smaller swizzle granularity is compatible with larger ones (32B is compatible with 64B and 128B), we can automatically merge to the smaller granularity.

## Changes

- `src/layout/layout.h`: Add `SwizzleMode` enum and function declarations
- `src/layout/gemm_layouts.cc`: Implement swizzle detection and merging logic
- `src/transform/layout_inference.cc`: Add automatic swizzle layout merging in conflict resolution
- `tilelang/tileop/gemm/gemm_wgmma.py`: Refactor shared layout inference with proper docstring
