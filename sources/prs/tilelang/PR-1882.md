<!-- upstream-excerpt-start -->
This PR aims to support writing high-performance warp-specialized 2cta gemm on Blackwell, optimizing GEMM on (8192, 8192, 8192) to ~1670TFlops. Thanks @Hamerlate for providing the dev machine.

* **New Features**

  * New public pass to enable Blackwell 2-CTA lowering

* **Improvements**
  * Examples updated with persistent and non-persistent single-/2-CTA GEMM variants and runtime selection/benchmarking output
