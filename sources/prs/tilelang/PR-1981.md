## Summary
- Extend `T.tma_copy()` to support TMA stores (shared -> global) with user-managed synchronization
- Make the `barrier` parameter optional — it is required for TMA loads but not needed for stores
- For stores, emit only `tma_store + tma_store_arrive` (no `tma_store_wait`), so users can batch multiple stores and call `T.tma_store_wait()` explicitly
