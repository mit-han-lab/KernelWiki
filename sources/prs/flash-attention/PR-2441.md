## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Initial saturating decode perf numbers, deepseek 64/512 shape and topk length = 2048.
```
Vanilla MLA
batch: 512, seqlen_q: 1, seqlen_k: 16384, nheads: 128, -> 1.98 ms, 1180.70 TFLOPS
DSA, no bitmask (topk selected assumed in bounds)
batch: 512, seqlen_q: 1, seqlen_k: 16384, nheads: 128, -> 0.31 ms, 955.47 TFLOPS
DSA, bitmask
batch: 512, seqlen_q: 1, seqlen_k: 16384, nheads: 128, -> 0.33 ms, 898.08 TFLOPS
```

Now added:
1. persistent kernel for perf ✅
2. expose through interface ✅
3. handle seqlen_q > seqlen_k when causal (kernel currently hangs) ✅

Tests added in `test_flash_attn_mla_absorbed` and `test_flash_attn_mla_absorbed_varlen`.

tcgen05 mma codegen is not very good for this kernel, will need to be revised for more perf.

Not planned in this PR: page table (though high priority), sliding window.

PR authored by myself and @jack-carlisle-2025
