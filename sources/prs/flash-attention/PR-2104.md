## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR implements a separate sharding scheme for calculating KV row addresses for SM100 forward, following the implementation in FA3. The load is broken into two stages now:

1. Each of the load warp threads independently calculates a disjoint set of row addresses.
2. A group of coalesced load threads accesses calculated addresses serially via shuffle sync.

This improves the memory bandwidth utilization when using irregular page sizes. Now hitting a peak of 5 TB/s and 1100+ TFLOPS for arbitrary page-size paged attention.

Other optimizations:
- Use thread0 head_dim indices for bound checking, known at compile-time
- Increase register allocation for load warps
- PR #1993 frees up 4 warps for loading when Q is small
