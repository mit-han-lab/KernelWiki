## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR extends the flexattention-style `score_mod` support from #1840 to the variable sequence length setting. The following cases are now covered:
- When `q` and/or `k` are varlen in any combination (TF, FT, TT, FF)
- PackGQA for varlen on SM90 only

This does incur a slight complexity overhead in defining `score_mod`s, but many cases -- particularly when not using auxiliary tensors -- no change is needed. We update the `score_mod` signature to pass in `seqlen_info`. This allows the user to access offsets within the `score_mod`, needed to index properly into packed auxiliary tensors. It also allows the user to access sequence lengths, making offset causal and other such mods simple.

The expected signature for `score_mod`s is now `(scores, b_idx, h_idx, q_idx, kv_idx, seqlen_info, aux_tensors)`.
