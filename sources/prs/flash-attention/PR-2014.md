## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR switches the sm100 fwd epilogue over to using the 4 correction warps when not using TMA store (e.g., when query seqlen is variable), instead of adding the empty warp. This also enables Paged KV in general with varlen since we eliminate the contention issue between producer and epilogue warps.

Will look at perf before merging.
