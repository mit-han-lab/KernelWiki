## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This feature aims to support arbitrary page sizes in the FA4 forward kernel.

The current implementation adapts the implementation of paged attention from `paged_kv.h`.

Optimizations not yet adapted:
- Using thread 0 copy atom to resolve some values at compile-time
- Sharded pointer computation + warp shuffle
