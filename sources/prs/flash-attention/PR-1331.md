## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cutlass 3.6 made some incompatible API changes to the SM90_TMA_LOAD ops and structs which now all have additonal cache_hint arguments. Since the paged attention code for FA3 derives from that code ( specifically the file copy_paged_sm90_tma.hpp), it needs to be adapted.

These changes aims for compatibility with both Cutlass 3.5 and 3.6 by using one or the other code variant depending on the Cutlass version (e.g. there are preprocessor statements to that effect). This should allow a smooth upgrade once the Flash Attention V2 repo as a whole upgrades Cutlass to 3.6+.

Functionally there is no change. copy_paged_sm90_tma_cutlass35.hpp is effectively identical to the old version, while copy_paged_sm90_tma_cutlass36.hpp adds support for the new cache_hint arguments, and is otherwise unchanged.

Additionally this PR includes a minor compatibility fix to _flash_attn_varlen_forward in FA3, which gives the block_table a default value of None.

I tested this also against Cutlass 3.6 ( e.g. current Cutlass main HEAD )
<!-- upstream-excerpt-end -->
