## PR Description
ATT, add local_window support in Hopper FAv3 and unittests.
* Local masking is checked in each mainloop iteration. It's possible to further optimize it by only checking local masking in the first m and last n iterations, and leaving iterations in-between unchecked. This PR doesn't do this optimization to make code easier to read.
* This support is only added to fp16 / bf16 for now. fp8 support will be in separate PRs.

## Tests
Added unittest for local attention.
`python3.9 -m pytest -q -s test_flash_attn.py` passed.

Benchmark: `python3.9 benchmark_attn.py`
No perf difference before v.s. after.
