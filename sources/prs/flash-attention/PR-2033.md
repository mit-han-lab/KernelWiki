## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
We enable deterministic mode for sm100 bwd kernel and fix outstanding race conditions.

PR includes:

1.  Sync compute warpgroup prior to releasing LSE (for tmem store fence) and release Psum + producer commit on dS (for tmem store fence and async smem fence); both were causing errors.
2. Sync compute warpgroup (not just sync warp) after `fence_view_async_tmem_load` in loop computing dS.
3. Add dq/dk/dv semaphores to interface and hook into sm100 bwd code.
4. Enable SPT schedule for causal deterministic.
5. Make placing dS in tmem or smem for `dK = dS.T @ Q` MMA a tuneable parameter and place in smem for causal deterministic; this is slightly faster.
<!-- upstream-excerpt-end -->
