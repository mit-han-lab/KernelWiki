## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
If TileN is not divisible by 32 (e.g, 208), by default EpiTile would be set to 128 x 32, which does not compile as TileN is required to be divisible by EpiTileN. We instead set EpiTileN to be gcd(32, TileN).
Cc @thakkarV @hwu36
