## Summary

  Implements grouped GEMM (C_g = A_g × B_g for each group g) on Hopper using CuTe DSL,
  extending the existing dense persistent GEMM with per-group TMA descriptor management.

  ## Kernel Design (`grouped_gemm.py`)

  - **Warp-specialized pipeline**: DMA warp group handles TMA loads and per-group
    tensormap updates; MMA warp group runs WGMMA and epilogue (TMA store)
  - **StaticPersistentGroupTileScheduler**: persistent tile scheduling across groups
  - **Per-group TMA descriptor updates**: supports both GMEM and SMEM update modes
  - **Data types**: fp16, bf16, fp8 (E4M3FN / E5M2), int8 with mixed A/B dtypes
  - **Configurable**: tile shapes (128×128, 128×256), cluster shapes, major modes
