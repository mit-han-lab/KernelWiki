## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Follow: https://github.com/NVIDIA/cutlass/pull/2719. Some SM120 kernels will use SM90 [Cooperative](https://github.com/NVIDIA/cutlass/blob/main/include/cutlass/gemm/kernel/sm90_gemm_tma_warpspecialized_cooperative.hpp)/[Pingpong](https://github.com/NVIDIA/cutlass/blob/main/include/cutlass/gemm/kernel/sm90_gemm_tma_warpspecialized_pingpong.hpp) Mainloop with SM100 TileScheduler. SM100 TileScheduler do not have `is_last_tile` function. This can cause compilation errors when we remove unnecessary conditional compilation.
In this PR, If SM120 blockscaled is detected at compile time, then bypass `launch_dependent_grids`.
<!-- upstream-excerpt-end -->
