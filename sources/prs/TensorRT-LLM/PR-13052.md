## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Closes #12716
## Summary
- Add fused CUDA kernel combining cross-head (full-dim) RMSNorm + RoPE into a single pass over the packed QKV tensor
- Eliminates extra global memory round-trip between separate norm and RoPE ops
- Supports interleaved and rotate_half RoPE modes, with CTA-level shared-memory reduction
- Enable by default for WAN (replaces the previous unfused path)
## Changes
- `fusedDiTQKNormRopeKernel.cu/h` — cross-head kernel + launcher
- `fusedDiTQKNormRopeOp.cpp` — torch op binding
- `utils.py` — inplace op registration for torch.compile
- `attention.py` — dispatch to cross-head kernel when `qk_norm_mode == "full"`
- `transformer_wan.py` — enable fused kernel by default for WAN
- `test_fused_dit_qk_norm_rope.py` — correctness tests (interleaved, rotate_half, batched, V-unchanged)
## Test plan
- `pytest tests/unittest/_torch/thop/parallel/test_fused_dit_qk_norm_rope.py`
- Cross-head correctness validated against PyTorch reference for WAN 1.3B (12 heads) and 14B (40 heads)
- Both interleaved and rotate_half RoPE modes tested
- V-unchanged tests confirm only Q/K are modified
- Batched input (B > 1) with tiled cos/sin embeddings

## Performance

Measured on a single A100 8
