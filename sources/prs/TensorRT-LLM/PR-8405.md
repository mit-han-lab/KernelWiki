## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Co-authored with @lfr-0531 @Tracin

This PR adds:
- DS-V3.2 support with
   - FP8 flow + BF16 KV cache
   - NVFP4 flow + BF16 KV cache
- MTP support (next_n=1)
- CUDA Graph support
- Indexer chunked prefill for long-context request (to avoid L^2 space complexity)

TODOs:
-  Dependency PR:  https://github.com/NVIDIA/TensorRT-LLM/pull/8488

Run command:
```
cat > extra_llm_api.yaml <<EOF
enable_attention_dp: true

moe_config:
  backend: DEEPGEMM

kv_cache_config:
  enable_block_reuse: false
EOF


trtllm-eval \
  --model ${llm_model_root}/DeepSeek-V3.2-Exp-hf/ \
  --tp_size 8 \
  --ep_size 8 \
  --extra_llm_api_options extra_llm_api.yaml \
  gsm8k

```
