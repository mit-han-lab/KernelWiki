## Summary

Add a fused CUDA kernel (`trtllm::fused_cat_fp8`) that combines BF16 tensor concatenation and FP8 E4M3 1×128 quantization into a single kernel launch. This replaces the sequential `cat → fp8_quantize_1x128` path in the DSA indexer's `_prep_q_or_k()`, reducing per-call kernel launches from 2+ down to 1.

### Changes
- **New CUDA kernel** (`fusedCatFp8.cu/h`): 1 warp (32 threads) per row, 8 rows per block. Vectorized 8-byte `int2` loads for BF16 inputs, 4-byte `uint32_t` stores for FP8 outputs. Per-row FP8 quantization with warp-reduced amax.
- **Template specialization** on `UseUe8m0`: eliminates runtime branching for scale format. UE8M0 path uses IEEE 754 bit manipulation instead of `ceilf(log2f(...))` + `exp2f(...)`. Hardware `rcp.approx.ftz` for fast reciprocal.
- **Non-contiguous input support**: accepts row strides directly, handling `torch.split()` views without a prior `.contiguous()` copy.
- **Torch op registration**: registered via `TORCH_LIBRARY_FRAGMENT` with fake tensor support for `torch.compile`.
- **DSA integration** (`dsa.py`): `_prep_q_or_k()` now calls the single fused op, removing imports for `maybe_compiled_cat` and `fp8_utils`.
