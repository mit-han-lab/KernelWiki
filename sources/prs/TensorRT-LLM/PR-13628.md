## Description

Add a fused 1x128 FP8 quantize + UE8M0 scale pack kernel for SM100, matching the layout produced by `deep_gemm.get_mn_major_tma_aligned_packed_ue8m0_tensor`. The new launcher writes per-block UE8M0 scales packed into uint32 directly from the quantize kernel, eliminating the standalone `pack_fp32_into_ue8m0` launch (~1.7% of GEN time on Flash TEP4 c128) and the `scale_1x128` launch (~3.4% of GEN time) on every fp8-block-scale GEMM input quantization.

The new path is gated behind `TRTLLM_FUSED_FP8_QUANT_PACK=1` (default off) and only engages on `SM>=100` to preserve existing behaviour everywhere else. With the gate off the call graph is byte-identical to the prior path.

### Performance — DSv4-Flash TEP4 c128

bs=256, conc=128, kv=0.85, mtp=0, gb200, 1280 prompts, side-by-side same-shape A/B from a single bench run:

| Config | sys tok/s | per-GPU tok/s | tpot ms |
|---|---:|---:|---:|
| `_FUSED_FP8_QUANT_PACK=0` | 3657.5 | 914.36 | 32.49 |
| `_FUSED_FP8_QUANT_PACK=1` | **4011.5** | **1002.87** | **29.59** |
| Δ | | | **+9.68%** |

### Accuracy — gsm8k 5-shot, lm-eval

`trtllm-eval --custom_tokenizer deepseek_v4 --apply_chat_template --system_prompt`. Same TEP4 c128
