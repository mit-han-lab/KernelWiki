## Purpose
To enable serving MXFP8 MoE models, this PR integrates SGLang’s SM100 expert-specialization MXFP8 blockscaled grouped kernels into vLLM so they are built, registered, importable, and test-covered in the vLLM codebase.
Source PR for adopted kernels: [sgl-project/sglang#13731](https://github.com/sgl-project/sglang/pull/13731).

This PR:
- Adds the renamed kernels `cutlass_mxfp8_grouped_mm` and `mxfp8_experts_quant` to vLLM’s `_C` build path (CUDA-gated for SM100-compatible targets).
- Renames and reorganizes kernel sources under:
  - `csrc/moe/mxfp8_moe/`
- Registers op schemas in `csrc/torch_bindings.cpp` and wires CUDA impls in the copied kernel files.
- Adds/updates Python wrappers in `vllm/_custom_ops.py`, including guarded `register_fake` hooks for fake/meta tracing compatibility.
- Integrates and renames the copied test to match vLLM conventions:
  - `tests/kernels/moe/test_cutlass_mxfp8_moe.py`
  - switches from `sgl_kernel` import to `vllm._custom_ops`
  - fixes argument ordering to match vLLM wrapper signatures
  - applies robust SM100/CUDA skip gating with updated kernel names.
- Preserves source provenance/citation headers in copie
<!-- upstream-excerpt-end -->
