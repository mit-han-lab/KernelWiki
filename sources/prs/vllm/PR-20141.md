### Purpose
Fix some warnings of the form:
```
warning #2361-D: invalid narrowing conversion from "char" to "signed char"
        at::cuda::CUDAGuard device_guard{(char)x.get_device()};
```

From `rg device_guard csrc`, the standard way of doing this is:
```
const at::cuda::OptionalCUDAGuard device_guard(device_of(x))
```
so this PR updates these spots to make them consistent.
