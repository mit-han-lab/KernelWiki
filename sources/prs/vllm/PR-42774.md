## Purpose

Padded nvfp4 quant kernel to remove additional copy, 15~40% kernel performance improvement, around 2.4%~5.7% e2e improvement

## Test

### E2E perf

```bash
CUDA_VISIBLE_DEVICES=0,1,2,3 \
vllm serve nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-NVFP4 \
  --quantization modelopt_fp4 \
  --tensor-parallel-size 4 \
  --linear-backend flashinfer_cutlass \
  --host 127.0.0.1 \
  --port 8000 \
  --max-model-len 2048 \
  --max-num-seqs 256 \
  --gpu-memory-utilization 0.9

vllm bench serve \
  --backend vllm \
  --model nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-NVFP4 \
  --endpoint /v1/completions \
  --dataset-name random \
  --random-input-len 64 \
  --random-output-len 128 \
  --ignore-eos \
  --request-rate inf \
  --max-concurrency 128 \
  --num-prompts 2000 \
  --percentile-metrics ttft,tpot,itl,e2el \
  --host 127.0.0.1 \
  --port 8000
```
