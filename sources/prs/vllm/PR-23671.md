## Purpose
Support Silu_Mul + NVFP4 quant fusion(following up #22448).
Add these compilation flags to enable the fusion:
```
--compilation-config {"custom_ops":["+silu_and_mul"],"pass_config":{"enable_fusion":true,"enable_noop":true}}
```
