## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
add nvfp4 support to reshape_and_cache_flash by introducing a new CUDA kernel for reshape_and_cache_flash that quantize and store k, v into kv_cache. The per page layout inside kv_cache is [k_data, k_scale, v_data, v_scale]. The layout is designed such that the last dimension of data and last two dimensions of scale are contiguous, which is a requirement of the kernel. A nvfp4_kv_cache_split_views function is added to split and reshape the kv_cache into these 4 parts.
