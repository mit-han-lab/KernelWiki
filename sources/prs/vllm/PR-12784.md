## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Forked from [this PR](https://github.com/vllm-project/vllm/pull/12519), we decide to separate the fp4 quantization and fp4 gemm as two PRs. (1) fp4 quantization focuses on how to convert higher precision to fp4, which only depends on the sm100a (i.e. ptx 8.7) and could be merged today (This PR); (2) fp4 gemm focuses on the gemm itself which needs to wait for the cutlass 3.8 to release.

And we have addressed the comments in the original PR in here as well for the quantization part. We will rebase the PR on this one later.

cc. @pavanimajety @kushanam
