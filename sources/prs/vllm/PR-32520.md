## Summary
This PR introduces further optimizations to the FP4 quantization kernels in vLLM, delivering substantial performance improvements across all tested shapes and batch sizes.

The main change is the use of **256-bit `load.global` instructions** enabled via **PTX 8.8**, which significantly reduces global memory instruction count and improves effective bandwidth. This optimization is **hardware- and toolchain-gated** and applies **only to SM100F GPUs with CUDA ≥ 12.9**.

In addition, the kernel uses an improved **partitioning scheme**.

---

## Key Changes
- Switched global memory accesses to **256-bit wide loads**.
- Reduced the number of global memory instructions, improving L2 utilization and global → L2 → SM efficiency.
- Applied a custom **partitioning scheme** to increase the occupancy on input matrices with large K-dim.
- Preserved correctness and numerical behavior.

---

## Hardware / Toolchain Requirements
- **GPU:** SM100F
- **CUDA:** ≥ 12.9 (PTX 8.8 required)

---

## Performance Impact
The new kernel is:
- **Consistently faster than the original and previous vLLM implementations**
- **Consistently faster than FlashInfer across all tested batch sizes and K values*
