## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR enables the offloading connector to work for cases where the kernel block size is different than vLLM's logical block size.

To efficiently copy blocks when the logical block size is greater
than the block size, we add an additional parameter to the swap_blocks
function that determines the size per each contiguous copy.

This fix addresses the same issue that was fixed in the NixlConnector in #28677.
