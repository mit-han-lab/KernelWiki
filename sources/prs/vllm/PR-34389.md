## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add PyTorch standard functional + out-variant pair for `scaled_fp4_quant`,
and extract duplicated FP4 scale allocation logic into shared utilities.


Old schema:
  scaled_fp4_quant(Tensor! output, Tensor input, Tensor! output_scale,
                   Tensor input_scale, bool is_sf_swizzled_layout) -> ()

New schemas:
  scaled_fp4_quant(Tensor input, Tensor input_scale,
                   bool is_sf_swizzled_layout) -> Tensor[]
  scaled_fp4_quant.out(Tensor input, Tensor input_scale,
                       bool is_sf_swizzled_layout, *,
                       Tensor! output, Tensor! output_scale) -> Tensor[]

With pytorch 2.12 release, this functional op will be transformed to its out variants:
<img width="780" height="372" alt="Screenshot 2026-03-02 at 6 04 05 PM" src="https://github.com/user-attachments/assets/923498bb-9837-45ed-9af0-7da70e8ca717" />

## Changes

**Schema (C++):**
- New functional default: `scaled_fp4_quant(input, input_scale, is_sf_swizzled_layout) -> (Tensor, Tensor)`
- New `.out` overload: `scaled_fp4_quant.out(input, input_scale, is_sf_swizzled_layout, *, output, output_scale) -> ()`
- Tagged `.out` with `torch.Tag.out_variant` for future Inductor auto-discov
