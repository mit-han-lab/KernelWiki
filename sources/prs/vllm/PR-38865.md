## Purpose

### What changed

This PR refactors the decode path of DeepseekV32IndexerMetadataBuilder and the supporting C++ kernels. No behavioral changes on any existing path.
                                                                                                                                                               vllm/v1/attention/backends/mla/indexer.py
- Remove offsets from DeepSeekV32IndexerDecodeMetadata. Per-token effective lengths are now pre-computed in the builder instead of being reconstructed at each call site.                                                                                                                                            - Allocate decode_seq_lens_buffer with the correct shape at init time: (max_num_seqs, next_n) for native MTP, (max_num_batched_tokens,) for flatten/plain decode. Fixed shape ensures stable CUDA graph addresses.                                                                                                   - Extract _prepare_decode_tensors() — the 60-line if/else block in build() is now a dedicated method returning (seq_lens, block_table, decode_lens, batch_size, requires_padding).
