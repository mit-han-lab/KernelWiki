## Purpose

#29424

This PR implements GPTQ support for MoE models with LoRA.

Previously, enabling LoRA on GPTQ-quantized MoE models would fail because `GPTQMarlinMoEMethod` did not explicitly support the modular GEMM interface required for LoRA. This PR enables the modular kernel path for GPTQ MoE when LoRA is active.

### Key Changes

1.  **Modular GEMM Selection (`vllm/model_executor/layers/quantization/gptq_marlin.py`):**
    *   Implemented `select_gemm_impl` in `GPTQMarlinMoEMethod` to allow switching to `MarlinExperts` or `BatchedMarlinExperts` when `is_lora_enabled` is true.
    *   Added weight aliases (`w13_weight`, `w2_weight`) to ensure compatibility with the modular kernel's expected attribute names.

    ```python
    def select_gemm_impl(self, prepare_finalize, layer):
        if not self.moe.is_lora_enabled:
             raise NotImplementedError(...)
        # Returns MarlinExperts verified for GPTQ
        # ...
    ```

2.  **Configuration (`vllm/model_executor/layers/fused_moe/config.py`):**
    *   Added `gptq_marlin_moe_quant_config` to generate the correct quantization descriptor for GPTQ Marlin MoE layers.
