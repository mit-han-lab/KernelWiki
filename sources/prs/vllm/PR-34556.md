## Introduction

[Humming](https://github.com/inclusionAI/humming/) is a highly flexible JIT quantization kernel library.

It supports inference for the vast majority of quantization types and offers performance superior to the Marlin kernel.

- **Supported Data Types:** W{1-8}A{16/8/4}
- **Currently Compatible Weight Types:** GPTQ / AWQ / FP8 / MXFP4 / NVFP4 / BITNET
- **Unsupported Types (No support planned):** GPTQ with `desc_act=True` / HQQ
- **Fully Supported GPU Architectures (Best Performance):** Turing / Ampere / Ada Lovelace / Hopper
- **Architectures Not Yet Fully Supported:**
    - Blackwell Datacenter (SM100): UMMA is not yet supported.
    - Blackwell Consumer (SM120): Performance is suboptimal in some cases as blockscale is not yet supported.


## Usage

Humming is currently an experimental feature. You must manually add `--quantization humming` to use this kernel. Beyond basic functionality, Humming currently uses three environment variables to customize advanced behavior.
