## Purpose

This PR fix the expert_ids padding value in moe_align_block_size kernel.
* Current `moe_align_block_size` kernel padding expert_ids is 0. But this should be -1, because the downstream kernel expect invalid expert_ids to be -1, see https://github.com/vllm-project/vllm/blob/v0.16.0/vllm/model_executor/layers/fused_moe/fused_moe.py#L431
* Updated test cases in test_moe_align_block_size.py
