## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
https://github.com/vllm-project/vllm/pull/12185 add triton moe wna16 kernel, but triton cannot reach the best performance when m is small. This PR add the moe wna16 cuda kernel. It have better generation speed than triton version when `num_seqs * top_k / num_experts` is small (for deepseek-v3/deepseek-r1, it have better performance when num_seqs <= 256). This PR also provides a better block config for triton moe wna16 gemm kernel.



The generation speed on 8*A100 + deepseek-v3-awq (tokens/s):
