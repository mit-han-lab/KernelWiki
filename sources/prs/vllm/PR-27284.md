## Purpose
1. Added swap AB optimization to CUTLASS FP8 GEMM on B200 (SM100) to improve performance for small batch size - M <=64 cases
2. Tuned kernel configs by leveraging nvMatmulHeuristics

**Context on Swap-AB Optimization**

For the 5th-generation Tensor Core (tcgen05.mma) instruction on SM100, the supported matrix shapes include 64 × N × 16 (with N a multiple of 8) and 128 × N × 16 (with N a multiple of 16), where M is fixed at 64 or 128. When the batch dimension M is small (<=64) , it can be beneficial to swap M and N to reduce padding overhead, since it is typically easier to ensure that N aligns with these required multiples.

Similar optimization done on H200: https://github.com/vllm-project/vllm/pull/20396/
