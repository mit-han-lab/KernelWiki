## Purpose

DeepGemm is updating to v2.0, which includes a new implementation for SM100 that expects block FP8 scales in E8M0 format https://github.com/deepseek-ai/DeepGEMM/pull/112

Previous context: https://github.com/vllm-project/vllm/pull/19820

We add a wrapper to support both Hopper (1.x) and Blackwell (2.x) interfaces
