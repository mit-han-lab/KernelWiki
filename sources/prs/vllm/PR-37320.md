## Purpose

- Add `no_act_and_mul` support to `CutlassExpertsFp4`, enabling non-gated MoE models (e.g. Nemotron-Nano) to use the CUTLASS nvfp4 kernel via `--moe-backend=cutlass`
- Add `is_gated` parameter to `get_cutlass_moe_mm_data` so the CUDA kernel computes the correct first GEMM problem size (`n` vs `2*n`) without an extra kernel launch

## Test Plan

- `vllm serve nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-NVFP4 --moe-backend=cutlass` and `python tests/evals/gsm8k/gsm8k_eval.py` gives `Accuracy: 0.321`
- Added test case to moe-refactor b200 tests as `tests/evals/gsm8k/configs/moe-refactor/Nemotron-Nano-30B-NvFp4-ModelOpt-vllm-cutlass.yaml` for CI testing
