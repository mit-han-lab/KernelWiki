## Purpose

FIX https://github.com/vllm-project/vllm/issues/28086

Inspired from [TRTLLM](https://github.com/NVIDIA/TensorRT-LLM/blob/eeb56c2848a23bb60acd82c158d086c4305b249b/cpp/tensorrt_llm/thop/noAuxTcOp.cpp#L37), we add the sigmoid, e_score_correction_bias, and 32bit output cast into the fused_grouped_topk CUDA kernel that we already use for DeepSeek-like models. Gives about a 4.5% speedup on a medium concurrency benchmark with nvfp4 deepseek on B200.

Ran a simple dummy profile with `LLM(model="deepseek-ai/DeepSeek-R1", max_model_len=1024, load_format="dummy", hf_overrides={"num_hidden_layers": 4})`
