# Introduction

This PR adds W4A8 support for marlin and moe marlin kernels:

- **Supported weight types**: INT4 without ZP (GPTQ), INT4 with ZP (AWQ), MXFP4 (Note: NVFP4 format is not yet supported because it uses a groupsize of 16, which is smaller than the currently supported minimum groupsize of 32).

- **Supported activation types**: INT8 (unsupported for MXFP4 weights), FP8 (E4M3).

W8A8-INT8 and W8A8-FP8 are also supported by the current kernel code, but they still have performance issues in MoE (They are faster than the default configuration but slightly slower than a finely tuned triton_fused_moe. To optimize W8A8, we need to tune `stages` and `num_threadblocks_per_sm`, which will bring significant changes).

To use this kernel:

```shell
# for int8 activation
export VLLM_MARLIN_INPUT_DTYPE=int8
# or for fp8 activation
export VLLM_MARLIN_INPUT_DTYPE=fp8
# then run a model that using marlin kernel
vllm serve Qwen/Qwen3-30B-A3B-GPTQ-Int4
```

Future plans include supporting different activation types for different layers, but this is not included in this PR.
