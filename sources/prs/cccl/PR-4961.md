## Description

closes #265

This PR implements a non deterministic reduce that use atomics. Currently, it only supports `cuda::std::plus<>` and contiguous `OutputIteratorT`s (since we are calling `atomicAdd`). If these conditions are not fulfilled it falls back to the default reduce.
