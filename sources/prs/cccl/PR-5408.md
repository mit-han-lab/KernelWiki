## Description

closes #5351

This PR consolidates `block_reduce_warp_reductions.cuh` with `block_reduce_warp_reductions_nondeterministic.cuh`. The nondeterministic file was initially added in PR #4961 as a copy of the original file. There were some comments on how to update the file in that PR, so this PR applies those same comments to the original file and combines the two as they share a lot of code.

There were some SASS differences in `cub.bench.reduce.sum.base`, so I compared the performance of both the default reduce and the nondeterministic one before and after these changes on the H100 and B200, and the performance was the same:
