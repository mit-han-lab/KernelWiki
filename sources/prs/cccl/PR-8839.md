## Description

closes #8838

This adds a focused CUB regression test and fixes the Warpspeed scan store path for shifted, widened output ranges.

The failing case is `DeviceScan::InclusiveScan` writing 64-bit output from 32-bit input through a shifted output pointer. In this case, the start masked store in the widened-output path can produce an illegal memory access. This patch applies the same style of NVCC optimizer barrier already used nearby in `squadStoreBulkSync` to the start masked-copy pointers, and avoids issuing a zero-byte middle bulk copy.

Testing performed:

- Verified the new regression test fails before the fix with `sync failed: an illegal memory access was encountered`.
- Verified the new regression test passes after the fix.
- Verified an existing CUB device scan shard passes after the fix.
- Verified the reduced cuVS IVF-PQ reproducer from #8838 passes after rebuilding against this change.
