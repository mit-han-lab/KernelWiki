## Description

<!-- Every PR should have a corresponding issue that describes and motivates the work done in the PR -->
closes https://github.com/NVIDIA/cccl/issues/6865

<!-- Provide a standalone description of changes in this PR. -->
The current implementation uses single block to reduce segments. This creates a performance bottleneck when segments are very large.
This PR implements two-phase segmented reduction where each segment is processed by multiple blocks, by dividing the single large segment into mulitple fixed size chunks and assigning each chunk to a block.
