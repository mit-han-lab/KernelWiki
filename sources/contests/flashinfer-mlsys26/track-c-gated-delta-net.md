# Track C: Gated Delta Net

## Official scope

The official contest page describes Track C as Gated Delta Net used in Qwen3-Next, with decode and prefill work. Submissions targeted NVIDIA Blackwell B200 GPUs and could be expert-crafted with agent assistance or fully agent-generated.
