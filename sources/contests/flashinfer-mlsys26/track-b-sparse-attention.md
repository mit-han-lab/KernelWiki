# Track B: Sparse Attention (DSA)

## Official scope

The official contest page describes Track B as DeepSeek Sparse Attention from DeepSeek V3.2, split into indexer and attention work. Submissions targeted NVIDIA Blackwell B200 GPUs and could be expert-crafted with agent assistance or fully agent-generated.
